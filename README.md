# Aurelia Wedding Atelier

Premium animated wedding planner website demo built with Next.js, TypeScript, Tailwind CSS, and Framer Motion.

## Install

```bash
npm install
```

## Run Locally

```bash
npm run dev
```

Open `http://localhost:3000`.

## Build

```bash
npm run build
```

## Deploy On Vercel

1. Push this project to GitHub, GitLab, or Bitbucket.
2. Import the repository in Vercel.
3. Keep the default Next.js settings.
4. Deploy.

Most editable content lives in `data/siteData.ts`, including brand name, phone number, packages, images, cities, and testimonials.
